
🎭 Comics United
 A Professional Networking Platform for Comedians

Comics United is a modern web application designed to connect comedians with venues, collaborators, and professional opportunities. The platform provides a curated venue database, networking tools, and a polished user experience tailored for both amateur and professional comedians.

---

🚀 Live Demo
Production Site: https://comics-united-beta.netlify.app

---

✨ Key Features

🏛️ Venue Database
- 31+ verified comedy venues
- Coverage across NY, CA, IL, TX, FL, PA
- Major cities: NYC, LA, Chicago, Austin, Miami, Philadelphia
- Open mic details: signup rules, costs, times, contact info

🎤 Comedian Networking Tools
- Professional comedian profiles
- Verification system
- Messaging system (planned)
- Rating & review system
- Filter by specialty, experience level, and more

🔍 Search & Filtering
- State → City hierarchical browsing
- Venue type filtering (club, bar, theater)
- Open mic toggle
- Full‑text search across venue descriptions

🎨 Modern UI/UX
- Glass‑morphism interface
- Responsive design
- Smooth animations
- Clean authentication flow

---

🛠️ Tech Stack

Frontend: React 18  
Build Tool: Vite  
Styling: Modern CSS (glass‑morphism)  
Backend (Dev): JSON Server  
Deployment: Netlify  
Auth: Local‑storage based (expandable to real auth providers)
